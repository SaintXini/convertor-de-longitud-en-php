# 📏 Conversor de Longitud

Aplicación web para convertir valores entre distintas unidades de longitud (milímetros, centímetros, decímetros, metros, decámetros, hectómetros y kilómetros), desarrollada con **PHP** puro y **Bootstrap** para la interfaz.

## 🛠️ Tecnologías utilizadas

- **PHP** — lógica del backend y procesamiento del formulario
- **HTML5** — estructura de la página
- **Bootstrap 5.3.3** — estilos y componentes responsivos (vía CDN)
- **CSS3** — estilos complementarios

## ⚙️ Funcionalidades

- Conversión de valores entre 7 unidades de longitud distintas.
- Conversión interna estandarizada a metros para simplificar los cálculos.
- Validación básica de unidad no válida.
- Resultado formateado con dos decimales.
- Interfaz responsiva gracias a Bootstrap.

## ▶️ Cómo ejecutar el proyecto localmente

1. Clona este repositorio:
   ```bash
   git clone https://github.com/tu-usuario/tu-repositorio.git
   ```
2. Asegúrate de tener PHP instalado (o usa XAMPP / Laragon / WAMP).
3. Coloca el proyecto en la carpeta de tu servidor local (por ejemplo, `htdocs`).
4. Levanta un servidor PHP:
   ```bash
   php -S localhost:8000
   ```
5. Abre tu navegador en [http://localhost:8000](http://localhost:8000)
